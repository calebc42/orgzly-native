# Orgzly Native restoration

Recovered from the archived POC checkout at commit 9a28575ddc869542342801884251a68ce213cd41.
The original history remains intact. The old bundled core, generated single-file
bundle and device deployment scripts are retired in favor of sibling Jetpacs
repositories. `LEGACY-PARITY.md` records historical claims, not current proof.

Visual reference: Orgzly Revived commit `30f1168abc3913bc986160261d77858586f13b64`,
particularly `app/src/main/res/values/colors.xml`, `dimens.xml`,
`layout/item_book.xml` and the note layouts. The port adapts those visual
conventions to Foundation; it is not a claim of pixel-for-pixel parity.

The historical GitHub URL is restored as `origin`; `archive` retains the local
recovery source. No remote fetch, push, new commit or history rewrite was
performed in the restored repository.
